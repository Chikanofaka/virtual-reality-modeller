# Floor-plan evolution evidence

Six original PNGs from the supplied `floor_plan_evolution.zip`, renamed for stable sorting. `manifest.json` records each original ZIP entry and SHA-256. No geometry or markings were edited. `contact-sheet.jpg` is a reduced inspection montage; use original PNGs to inspect details.

The visible plan versions are v1.0 through v1.5, independent of the runtime versions V1–V7. Every image says it is photo-derived and not to scale. Red markings are source annotations; their author and intended wording cannot be reconstructed from the images alone. The folder is supplied project evidence, not a surveyed floor plan.
