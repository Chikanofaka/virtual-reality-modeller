# Ingest spatial evidence

Inputs: {{uploaded_files}}, {{owner_notes}}, {{prior_revisions}}.

Inventory every source with a stable ID, original name, SHA-256, media type and coverage. Preserve originals. Read plans and annotated images visually; capture key video timestamps where available. Identify boundary, units, scale markers, room names/roles, entrances, openings, circulation, furniture/material references and conflicts. Do not mistake a photorealistic planning illustration for a measured plan. Do not execute scripts inside uploaded archives during ingestion.

Output: source inventory; concise supported-facts table with source ID/page/time; contradiction list; missing-data queue ordered by impact on navigation and plan fidelity. Mark unavailable/unreadable attachments explicitly. Start interrogation with the highest-impact unanswered questions, reusing clear earlier answers.
